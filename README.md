# esmeringle ⚡

> Anonymous 1-on-1 live text chatting. Built with Next.js, Socket.io, TypeScript, and Tailwind CSS.

## Features

- **1-on-1 Realtime Chat**: Instant peer-to-peer matchmaking with zero wait stalls.
- **Custom Aliases**:
  - 👨 **Dawg** (Male / Lalaki)
  - 👩 **Amiga** (Female / Babaye)
  - 👤 **Anon** (Prefer not to say / Dili lang ko magsaba)
- **Multi-Language Support**:
  - **Bisaya (Cebuano)** (Default)
  - **English**
- **Light & Dark Theme**: Sleek native-feeling interface with light mode by default.
- **Session Privacy**: Isolated `sessionStorage` management with zero accounts or sign-ups.
- **Procedural Sound Synthesis**: Built-in sound effects using Web Audio API without external audio assets.
- **Keyboard Shortcuts**: Press `ESC` anytime to instantly rematch or cancel.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
PORT=3005 npm run dev
```

Open [http://localhost:3005](http://localhost:3005) in your browser.

### 3. Build for Production
```bash
npm run build
npm start
```
